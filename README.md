Diwali Sales Analysis - 
This project was built by following a YouTube tutorial by Rishabh Mishra. I performed the analysis independently and wrote my own conclusions.
Tools Used: Python, Pandas, Matplotlib, Seaborn
Key Findings: Married women aged 26–35 from UP, Maharashtra and Karnataka, working in IT, Healthcare and Aviation, are the most active Diwali buyers preferring Food, Clothing and Electronics.
